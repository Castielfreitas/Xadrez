# Integrity coverage

The computer's `displayRating` is cosmetic. Its server engine keeps Skill Level 20 and UCI_LimitStrength=false, and its internal rating remains 3500. Human rating verification still updates real human rating. Public computer ratings are explicitly indicative and computer tournament disclosures state maximum strength.

Visible extension resources are scanned on startup and on subtree injection, URL changes and removal, including nested script, iframe, stylesheet, object and embed resources. No extension inventory, extension identifier, URL, other tab or screenshot is collected by this scanner. Local boards block human move entry while such resources remain. Online boards additionally report consented boolean presence transitions; the server blocks only the reporting player's moves until a clear transition. A persistent board notice explains the block and continuing clock.

The same server move guard applies to free/paid matches and tournament rounds. Existing ownership, turn, ply, clock, account-status validation and server-side human move analysis remain. Online integrity consent and analysis were already enabled in production. Raw page/extension signals are client-untrusted, can have legitimate causes and do not automatically ban accounts. Server engine evidence and human review remain necessary for account sanctions.

Browser code cannot prevent all extensions, external engines, screenshots or automation. A modified client can suppress client-side reporting. Local/anonymous training does not provide authoritative server analysis or account sanctions. This release does not claim complete anti-bot protection or equivalence to a proprietary platform.
