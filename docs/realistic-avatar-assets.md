# Retratos realistas da Arena

Dez retratos originais gerados com a ferramenta integrada de imagens; exportados para WebP 512 × 512. Arquivos em `public/avatars/realistic/`. Os SKUs e preços anteriores foram preservados. Os 1.280 itens da coleção especial combinam dez retratos com paletas, auras e ornamentos; não são 1.280 rostos diferentes.

## Direção visual / prompt comum

Use case: stylized-concept. Asset type: premium square avatar portrait for Arena Xadrez game shop. Create ONE original high-end AAA videogame character portrait. Photorealistic cinematic 3D rendering, extremely detailed physically based materials, subtle wear, dramatic soft studio key light and rim light, deep charcoal backdrop, rich bronze-gold highlights. Head and upper shoulders centered, face fully inside central 70 percent for circular cropping. Strong unique silhouette. Sophisticated adult game aesthetic. No text, no logo, no watermark, no UI, no collage, no borders. Square portrait.
